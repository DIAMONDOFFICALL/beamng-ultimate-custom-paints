# Installation Guide

## English

### Method 1 — Recommended (Ready settings.json)

1. Open your BeamNG user folder:
   ```
   C:\Users\<YourName>\AppData\Local\BeamNG\BeamNG.drive\current\settings\cloud\
   ```
2. **Backup** your current `settings.json` file.
3. Go to the `settings_packs` folder in this repository.
4. Choose one of the files:
   - `settings_ALL_COMBINED.json` → All 479 presets (Recommended)
   - Or any single category file (Manufacturer, JDM, Racing, etc.)
5. Rename the chosen file to `settings.json`.
6. Replace the original `settings.json` with it.
7. Start BeamNG.drive.

### Method 2 — Manual (Only presets)

1. Open `settings.json` with a text editor (Notepad++ or VS Code recommended).
2. Find the line that starts with `"userPaintPresets":`.
3. Replace the entire value with the content from `userPaintPresets_ALL_COMBINED.json`.
4. Save the file and restart the game.

## Türkçe

### Yöntem 1 — Önerilen (Hazır settings.json)

1. BeamNG user klasörünü aç:
   ```
   C:\Users\<KullanıcıAdın>\AppData\Local\BeamNG\BeamNG.drive\current\settings\cloud\
   ```
2. Mevcut `settings.json` dosyasını **yedekle**.
3. Bu repodaki `settings_packs` klasörüne gir.
4. Bir dosya seç:
   - `settings_ALL_COMBINED.json` → 479 rengin hepsi (Önerilen)
   - Veya tek kategori dosyalarından birini
5. Seçtiğin dosyayı `settings.json` olarak yeniden adlandır.
6. Orijinal dosyanın üzerine kopyala.
7. BeamNG.drive’ı başlat.

### Yöntem 2 — Manuel

1. `settings.json` dosyasını Notepad++ veya VS Code ile aç.
2. `"userPaintPresets":` ile başlayan satırı bul.
3. Değerini `userPaintPresets_ALL_COMBINED.json` içeriğiyle değiştir.
4. Kaydet ve oyunu yeniden başlat.
